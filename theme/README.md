# theme — Omarchy color themes

Four coherent themes for Omarchy 4 (the `colors.toml` format plus generated
per-app configs), all derived from one base palette:

| Theme | Description | Generated by |
|---|---|---|
| [`las/`](las/) | base — dark forest green ("Las") | — |
| [`ogien/`](ogien/) | "Las" remap — green → violet (HLS +140°) | `tools/ogien-hsl-remap.py` |
| [`ciemny-las/`](ciemny-las/) | "Las" midnight — surfaces at ×0.10 lightness | `tools/darkify.py` |
| [`ciemny-ogien/`](ciemny-ogien/) | "Ogien" midnight | `tools/darkify.py` |

Each theme ships `colors.toml` (Omarchy 4 palette), per-app configs
(btop, chromium, eza, gtk, icons), 11 wallpapers `backgrounds/*.webp`
(WebP 2880×1800), a `preview.webp` and `LICENSE-upstream-MIT` (base theme
attribution — MIT).

Wallpapers are stored as **WebP** (q88): at panel resolution they are a
fraction of the size of the source JPGs at similar quality. Convert with
`tools/convert-webp.sh` (or ImageMagick) — see the script header.

`tools/` — variant pipeline and quality checks:
- `darkify.py` — midnight variants (darkens surfaces only; keeps text contrast)
- `ogien-hsl-remap.py` — "Ogien" variant (green→violet hue rotation)
- `contrast-check.py` — WCAG 2.1 contrast ratios for key token pairs
- `build-dark-themes.sh` — build + install midnight variants into `~/.config/omarchy/themes`
- `convert-webp.sh` — JPG/PNG → WebP (q88), resolution-preserving

## Install

```bash
omarchy theme set las                 # or: ogien / ciemny-las / ciemny-ogien
omarchy theme refresh
omarchy theme bg set theme/las/backgrounds/5-FG.webp
```
